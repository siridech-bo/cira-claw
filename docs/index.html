What is CiRA CLAW?

CiRA CLAW is an OpenClaw-inspired headless gateway daemon that manages AI inference on edge devices (NVIDIA Jetson, Raspberry Pi, Windows PCs) in factory environments. It combines a powerful inference runtime, real-time video streaming with WebRTC support, AI-powered automation rules, signal protocol bridges, and a modern web dashboard.

Key Features

🎥

WebRTC Streaming New

Ultra-low latency video streaming via go2rtc with automatic fallback to MJPEG and polling modes.

🤖

AI-Powered Agent

Claude-powered conversational agent for natural language device control and automation queries.

📊

Signal Dashboard New

Real-time signal monitoring from all nodes with filtering, history, and protocol bridges.

⚡

Multi-Format Inference

Support for NCNN, Darknet, ONNX, and TensorRT models with YOLOv3-v11 detection.

🔧

JavaScript Rule Engine

Create automation rules with visual flow diagrams and AI-assisted editing.

🔌

Protocol Bridges

MQTT and Modbus TCP integration for IoT and PLC communication.

Quick Start

1. Installation

# Clone the repository git clone https://github.com/siridech-bo/cira-claw.git cd cira-claw # Install dependencies npm install # Initialize configuration npm run cli -- onboard

2. Run the Gateway

# Development mode npm run dev # Production build npm run build npm start # Windows: Use batch files start-system.bat # Start gateway + go2rtc

3. Open Dashboard

Navigate to http://localhost:18790 in your browser.
