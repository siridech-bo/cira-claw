REST API

Base URL: http://localhost:18790

GET /api/status Get gateway status

Response

{ "status": "running", "version": "1.0.0", "uptime": 3600, "nodeCount": 3, "go2rtcEnabled": true }
GET /api/nodes List all nodes

Response

[ { "id": "jetson-line1", "name": "Production Line 1", "type": "jetson-nano", "host": "192.168.1.101", "status": "online", "lastSeen": "2026-05-29T12:00:00Z" } ]
GET /api/nodes/:id Get node details

Parameters

Name Type Description
id string Node ID required

Response

{ "id": "jetson-line1", "name": "Production Line 1", "type": "jetson-nano", "host": "192.168.1.101", "ssh": { "user": "cira", "port": 22 }, "runtime": { "port": 8080 }, "models": [{ "name": "scratch_v3", "task": "detection" }] }
GET /api/nodes/:id/status Check node health

Response

{ "online": true, "fps": 24.5, "inferenceTime": 42, "model": "scratch_v3", "uptime": 86400 }
GET /api/nodes/:id/stream Get stream URLs (MJPEG + WebRTC)

Response

{ "nodeId": "jetson-line1", "streams": { "mjpeg": "http://192.168.1.101:8080/stream/annotated", "raw_mjpeg": "http://192.168.1.101:8080/stream/raw", "websocket": "ws://192.168.1.101:8080/ws/video", "webrtc": "http://localhost:1984/api/webrtc?src=jetson-line1-annotated", "raw_webrtc": "http://localhost:1984/api/webrtc?src=jetson-line1-raw" }, "go2rtcEnabled": true }
GET /api/nodes/:id/snapshot Get camera snapshot

Query Parameters

Name Type Description
annotated boolean Include detection overlays (default: true)

Response

Returns JPEG image with Content-Type: image/jpeg

POST /api/nodes/:id/model Switch active model

Request Body

{ "model": "yolov8n" }

Response

{ "success": true, "model": "yolov8n" }
GET /api/rules List automation rules

Response

[ { "id": "rule-001", "name": "Defect Alert", "enabled": true, "nodeId": "jetson-line1", "trigger": "detection" } ]
POST /api/rules Create automation rule

Request Body

{ "name": "Defect Alert", "nodeId": "jetson-line1", "trigger": "detection", "code": "function evaluate(ctx) { ... }", "params": { "threshold": 3 } }
GET /api/signals Query signal history

Query Parameters

Name Type Description
nodeId string Filter by node
type string Signal type (detection, vibration, anomaly)
limit number Max results (default: 100)

WebSocket Events

Connect to ws://localhost:18790/ws

node:status

Node online/offline status change

node:detection

Real-time detection results from nodes

signal:update

Signal value changes from bridges

rule:triggered

Rule execution and action results

page:reload

Server-triggered page reload for memory management

page:reload_warning

Warning before scheduled page reload

Example: Subscribe to Detection Events

// Connect to WebSocket const ws = new WebSocket('ws://localhost:18790/ws'); ws.onmessage = (event) => { const msg = JSON.parse(event.data); if (msg.type === 'node:detection') { console.log('Detections:', msg.payload.detections); } if (msg.type === 'page:reload_warning') { console.log('Page will reload in', msg.payload.secondsUntilReload, 'seconds'); } };
