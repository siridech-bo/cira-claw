Core Components

Gateway (Node.js/Fastify)

Central hub that manages all communication between clients, edge devices, and external services.

  • HTTP REST API server
  • WebSocket real-time events
  • Static file serving for dashboard
  • Node management and health checks

Dashboard (Vue.js)

Modern web interface for monitoring and controlling the entire system.

  • Real-time camera streams
  • Device status monitoring
  • Rule management UI
  • AI chat interface

AI Agent (Claude)

Conversational AI for natural language device control and queries.

  • Tool use for device control
  • Rule creation assistance
  • Status queries and reports
  • Multi-channel support

go2rtc (WebRTC)

Low-latency video streaming server for real-time monitoring.

  • WebRTC with STUN/TURN
  • MJPEG source ingestion
  • Multi-client streaming
  • Cross-platform support

Signal Bridge

Protocol translator that connects detection events to industrial systems.

  • MQTT publishing
  • Modbus register mapping
  • State persistence (SQLite)
  • Signal aggregation

CiRA Runtime (libcira)

C/C++ inference engine running on edge devices.

  • Multi-format model loading
  • YOLO detection + NMS
  • Camera capture
  • HTTP streaming server

Data Flow

Detection Flow

1

Camera Capture

Edge device captures frames from connected camera using OpenCV.

2

Inference

Frame is processed through YOLO model (NCNN/Darknet/ONNX/TensorRT).

3

Detection Output

Bounding boxes, labels, and confidence scores are extracted via NMS.

4

Stream & Signal

Annotated frame is streamed via MJPEG/WebRTC. Detection signal sent to gateway.

5

Rule Evaluation

Gateway evaluates rules against detection data and triggers actions.

WebRTC Streaming Flow

1

Stream Registration

Gateway registers node's MJPEG stream URL with go2rtc service.

2

Client Request

Dashboard requests WebRTC stream for a specific node.

3

WebRTC Negotiation

go2rtc handles SDP offer/answer and ICE candidates via STUN.

4

Peer Connection

Direct peer-to-peer video stream established with ~100ms latency.
